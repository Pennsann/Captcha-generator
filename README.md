## Features
- Four CAPTCHA Types (Text-Based, Image-Based, Math-Based and reCAPTCHA Checkbox)
- Refresh Option (Regenerate a new CAPTCHA for each type)
- User-Friendly UI (Clear instructions for each CAPTCHA type , Buttons for submission and refresh)

## Tech stack
- C#
- .Net windows forms

  ## How to use
  1. Clone the repository
  2. Open the solution in Visual Studio
  3. Run the project
